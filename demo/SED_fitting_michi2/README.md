# michi2 SED fitting demos

| Example | Directory | What it shows | Runtime |
|---------|-----------|---------------|---------|
| **1. Minimal** (start here) | [`example_GN20/`](example_GN20/) | 10-band optical–FIR SED of GN20 (z=4.055); deploy → trial → sampling-3000 fit | a few minutes |
| **2. Full A³COSMOS source** | [`ID_628146/`](ID_628146/) + [`demo.bash`](demo.bash) | ~100-band UV–radio photometry of an A³COSMOS source (z=1.4456) | ~5 min at `-sampling 3000` |

Both are run the same way (BASH shell):

```bash
source /path/to/Crab.Toolkit.michi2/SETUP.bash
cd example_GN20/    # or: cd ID_628146/ && bash ../demo.bash
bash run_demo.bash
```

Note: the `results_fit_5/` outputs and the unzipped `lib.*.SED` libraries
are NOT committed — they are (re)generated by each run.

Caveat for example 2: `datatable_photometry.txt` contains duplicated
wavelengths, and the `michi2_filter_flux.py` preparation step currently
crashes on such tables under numpy ≥ 2 (see "Known issues" in the main
README). If you hit that, either run under numpy < 2, or pre-generate
`fit_5.in` yourself (3 columns: wavelength_um, flux_mJy, flux_err_mJy,
duplicates removed) — the wrapper reuses an existing `fit_5.in`.
